Programming Constructs

Every program, no matter how big, is built from just three basic blocks: sequence, selection and iteration. Read through, tap each "True or False" to check yourself, then complete your Educake homework.

01
The big picture

🧱 The Three Building Blocks

Every program is made by putting these three things together, over and over again:

  • Sequence — steps happen one after another, in order.
  • Selection — the program makes a choice, using IF.
  • Iteration — the program repeats something, using a loop.
You don't need anything else. Every program you will ever see is built from these three things, combined in different ways.
02
One thing after another

📋 Sequence

  • Sequence means the lines of code run in order, from top to bottom.
  • The order matters. If you swap two lines around, the program can stop working properly.
01name = input("What is your name?") 02print("Hello " + name)

Line 01 runs first and stores the name. Line 02 runs second and uses it. If you swapped the lines, the program would try to use a name it hasn't been given yet.

True or False? In sequence, the order of the lines does not matter.
✘ False — the order always matters. Each line often depends on something that happened before it.
03
Making a choice

🔀 Selection

  • Selection is when a program chooses what to do next, using IF, ELIF and ELSE.
  • Only one path is followed each time the program runs — the program picks the first condition that is true.
01speed = int(input("Enter speed: ")) 02if speed > 50: 03 result = "Issue fine & 3 points" 04elif speed > 40: 05 result = "Issue fine" 06else: 07 result = "Within limit" 08print(result)

If the driver's speed is 35, none of the first two conditions are true, so the program falls all the way to else and prints "Within limit".

True or False? In an IF/ELIF/ELSE chain, more than one branch can run at the same time.
✘ False — only one branch runs. As soon as the program finds a condition that is true, it runs that branch and skips the rest.
04
Doing it again

🔁 Iteration

  • Iteration means repeating a set of instructions. This is also called a loop.
  • FOR loops repeat a fixed number of times — you know exactly how many before it starts.
  • WHILE loops repeat until a condition changes — you don't always know how many times in advance.
01for i in range(1, 6): 02 print(i)

This FOR loop always runs exactly 5 times, printing 1, 2, 3, 4, then 5.

01n = int(input("Enter a number: ")) 02while n < 200: 03 n = n * 2

This WHILE loop keeps doubling n until it reaches 200 or more. It might run 2 times, or 20 times — it depends what number the user types in.

Quick way to tell them apart: if you can say exactly how many times it will repeat before the program runs, it's a FOR loop. If it depends on something happening, it's a WHILE loop.
True or False? A FOR loop is used when you know exactly how many times something should repeat.
✔ True — FOR loops are count-controlled, so the number of repeats is fixed before the loop starts.
05
Spot the construct

🧩 Putting It Together

Real programs mix all three constructs together. Read the code below and see if you can spot each one.

01total = 0 02for i in range(1, 4): 03 mark = int(input("Enter mark: ")) 04 if mark >= 50: 05 print("Pass") 06 else: 07 print("Fail") 08 total = total + mark 09print(total)
  • Line 01 and line 09 are sequence — they run in order, once each.
  • Lines 02–08 are inside a FOR loop — this is iteration.
  • Lines 04–07 are an IF/ELSE — this is selection, and it happens inside the loop each time it repeats.
Constructs are often nested — one sits inside another, like the IF/ELSE sitting inside the FOR loop above. Exam questions often ask you to find the first line where a construct is used, so read carefully from the top.
True or False? A program can only use one construct (sequence, selection or iteration) at a time — never more than one together.
✘ False — constructs are combined constantly. Selection is very often found nested inside iteration, just like in the example above.
