Programming Concepts

This page covers some key building blocks behind every program: variables, constants and subroutines. Read through, tap each "True or False" to check yourself, then complete your Educake homework.

01
Storing data

📦 Variables & Constants

  • Variable — a named location in memory that can change while the program runs.
  • Constant — a named location in memory that cannot change while the program runs.
  • Using meaningful names (like score, not x) makes code easier to read and debug.
01VAT_RATE = 0.2 02price = 19.99

VAT_RATE never changes, so it's a constant. price is different for every item, so it's a variable.

True or False? A constant's value can be changed later in the program.
✘ False — once set, a constant cannot be changed while the program runs. If it needs to change, it should be a variable instead.
02
Reusable blocks of code

🧩 Subroutines

  • A subroutine is a named block of code that can be run — called — whenever it's needed, just by using its name.
  • There are two types: a procedure and a function.
  • Using subroutines means you don't have to write the same code out again and again.
01def greetUser(): 02 print("Hello!") 03 04greetUser()
True or False? A subroutine has to be written out again every time you want to use it.
✘ False — that's the whole point of a subroutine. You write it once, then call it by name whenever you need it.
03
Sending data in

📥 Parameters

  • A parameter is a value passed into a subroutine so it can use it.
  • This lets the same subroutine work with different data every time it's called.
01def greetUser(name): 02 print("Hello " + name) 03 04greetUser("Alex") 05greetUser("Sam")

name is the parameter here — the subroutine uses whatever value is passed in when it's called.

True or False? A subroutine can only ever have one parameter.
✘ False — a subroutine can have more than one parameter, separated by commas, e.g. def addNumbers(a, b):
04
Getting data back

📤 Return Values

  • A function is a subroutine that returns a value to the code that called it, using return.
  • A procedure does not return a value.
01def addNumbers(a, b): 02 return a + b 03 04result = addNumbers(4, 7) 05print(result)
Common mistake: printing a value inside a subroutine instead of returning it. If a question asks for a return value, using print() instead will not gain the mark.
True or False? A procedure and a function are exactly the same thing.
✘ False — a function returns a value using return. A procedure does not return a value.
05
Kept inside

🔒 Local Variables

  • A local variable is declared inside a subroutine.
  • It only exists while the subroutine is running, and can't be used outside it.
01def calculateArea(width, height): 02 area = width * height 03 return area

area is local — it disappears once calculateArea() finishes running. Trying to use it outside the subroutine would cause an error.

True or False? A local variable can be used anywhere in the program, even outside the subroutine it was created in.
✘ False — local variables only exist while their subroutine is running, and can't be accessed from outside it.
