Lesson 3 — Linear Search for Pattern Validation

The scenario

Range checks and length checks work well for numbers and simple limits. But what if a value needs to match one of a specific set of allowed values — like a postcode area code that must be one of a handful the company actually delivers to?

A range check can't do this — there's no numeric "range" for "SW1A" or "M1". Instead, we need to search a list of allowed values to see if the entered one is there. That's exactly what linear search does.

Key vocabulary

TermMeaning
Linear searchChecking each item in a list, one after another, until a match is found or the list ends.
TargetThe value being searched for.
TraversalMoving through each item of a list in turn.
Allowed listThe set of values considered valid — what the target is checked against.
