Lesson 6 — Authentication with Dictionaries

The scenario

Last lesson's login system worked — but only for a single, hard-coded username and password. A real system needs to authenticate many different people, each with their own login details.

You already know dictionaries from earlier this year. A dictionary is the natural way to store many username-password pairs together, with each username directly linked to its correct password.

Key vocabulary

TermMeaning
DictionaryA data structure that stores pairs of keys and values, e.g. a username linked to its password.
KeyThe value used to look something up — here, the username.
ValueThe data stored against a key — here, the password.
LookupRetrieving the value stored for a given key.

Worked example


      
username in users checks the username exists as a key; users[username] looks up its stored password to compare.
