Lesson 5 — Authentication: Username & Password

The scenario

Your validation and search code from earlier lessons can make sure data is sensible and formatted correctly — but none of it checks who is using the system. A perfectly validated postcode doesn't stop the wrong person logging in.

Authentication confirms identity — usually with a username and password — before letting someone access a system at all.

Key vocabulary

TermMeaning
AuthenticationConfirming a user's identity, typically with a username and password.
Login attemptA single try at entering the correct username and password.
Lock-outBlocking any further attempts once a limit of failed logins has been reached.
