Lesson 4 — Testing: Test Data & Error Types

The scenario

Your validation and search code from Lessons 1–3 probably worked when you tried it. But "worked once" isn't the same as "works properly" — a real user might type something you never tried, and a bug that only shows up on unusual values can slip through unnoticed.

Testing means deliberately trying a range of different values to check a program behaves correctly — not just the values that are easy or obvious.

Key vocabulary

TermMeaning
Normal dataA typical, expected value that should clearly pass.
Boundary dataA value right at the edge of an accepted range, on either side.
Erroneous dataA value that should clearly be rejected — invalid, out of range, or the wrong type.
Syntax errorBreaks Python's rules — the program won't run at all.
Logic errorThe program runs, but produces the wrong result.
