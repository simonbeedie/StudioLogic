The basics

🖥️ What's Inside the CPU?

The CPU (Central Processing Unit) is the part of the computer that fetches, decodes and executes instructions. It's built from several components working together — click any box in the diagram to find out what it does.

👆 Click a component above to see what it does.
True or False? The ALU performs calculations and logical comparisons.
✔ True — the Arithmetic Logic Unit handles all the arithmetic (like +, −) and logical (like >, =) operations.
True or False? The Control Unit stores the result of a calculation.
✘ False — that's the Accumulator's job. The Control Unit decodes instructions and directs the other components.
How components talk to each other

🚌 The Three Buses

A bus is a set of wires that carries signals between the CPU and memory. There are three buses, each carrying something different. Press play to watch each one in action.

  • Address bus — carries a memory address, one direction only: from the CPU to memory.
  • Data bus — carries the actual data or instruction, and works in both directions.
  • Control bus — carries signals such as read/write commands, so memory knows what to do with the address and data it's just received.
Press "Play buses" to see each one work in turn.
True or False? The address bus can carry data in both directions.
✘ False — the address bus is one-directional: only the CPU sends addresses to memory.

Not all storage is equal

🏁 Cache vs RAM vs Secondary Storage

Cache, RAM and secondary storage (like an SSD or HDD) all store data — but at very different speeds. Press "Start race" to see how they compare. (This shows relative speed only, not real figures.)

Speed and capacity are a trade-off: cache is fastest but tiny and expensive per byte; secondary storage is slowest but huge and cheap per byte; RAM sits in between.
True or False? Secondary storage is usually bigger in capacity than RAM.
✔ True — secondary storage (like an SSD) typically holds far more than RAM, but is much slower to access.
True or False? Data in RAM is kept permanently, even when the power is off.
✘ False — RAM is volatile, meaning its contents are lost when the power is turned off. Secondary storage keeps data permanently.
Check what you've learned

📝 Computer Systems Quiz

Answer all the questions, then press "Check my answers" at the bottom.

1. Which component performs calculations and logical comparisons?

The ALU (Arithmetic Logic Unit) carries out all arithmetic and logical operations.

2. Which register holds the address of the next instruction to be fetched?

The Program Counter (PC) always holds the address of the next instruction.

3. How many directions can the address bus carry signals in?

The address bus is one-directional: only the CPU sends memory addresses.

4. Which bus carries the actual instruction or value being transferred?

The data bus physically carries the data or instruction itself.

5. Once an instruction has travelled from memory to the CPU, which register temporarily holds it?

The MBR (Memory Buffer Register) holds data or an instruction just fetched from memory, before it moves to the CIR.

6. Which component decodes an instruction to work out what it means?

The Control Unit (CU) decodes the instruction in the CIR and directs the rest of the CPU.

7. How many main stages are there in the Fetch-Execute cycle?

Fetch, Decode, Execute — three stages, repeated for every instruction.

8. Which type of storage is fastest, but also smallest in capacity?

Cache is the fastest, but it's also the smallest and most expensive per byte.

9. True or false: RAM keeps its data permanently, even without power.

False — RAM is volatile. Its contents are lost when the power is switched off.

10. Where might the result of an ALU calculation be stored?

The Accumulator (ACC) is used to store the result of a calculation.
