What is this, and why two websites?

Two sites, one course

Microsoft Learn hosts the actual lessons — the explanations, examples, and interactive code exercises. This is where you do the learning.

freeCodeCamp tracks your progress and hosts the final certification exam. Completing a module on Microsoft Learn earns you a "trophy" — freeCodeCamp checks off that section once you confirm you've done it.

You need both: do the learning on Microsoft Learn, then tick it off on freeCodeCamp so your certificate progress is recorded. At the end of all 6 courses, you'll sit the official exam on freeCodeCamp to earn the Foundational C# with Microsoft certificate.

One-Time Setup (do this first)

  • Install Visual Studio Code (not Visual Studio) — code.visualstudio.com
  • Install the C# Dev Kit extension from inside VS Code (Extensions tab → search "C# Dev Kit")
  • Create a free account at freecodecamp.org and start the course here: Foundational C# with Microsoft
