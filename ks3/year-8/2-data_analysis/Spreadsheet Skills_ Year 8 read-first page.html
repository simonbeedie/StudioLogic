The grid

Every spreadsheet is built from the same few parts. Learn their names first.

Cell

One box in the grid. A cell holds a single data point, such as a name, a number or a date.

Column

A line of cells going up and down (vertical). Columns are named with letters: A, B, C…

Row

A line of cells going across (horizontal). Rows are named with numbers: 1, 2, 3…

Range

A group of cells that you select together, so you can format them or use them in a calculation.

Memory trick: a column is like a tall pillar holding up a building, so columns go up and down. Rows are like rows of seats in a cinema, so they go across.
Cell reference: the name of a cell, made from its column letter and then its row number. The cell where column C meets row 4 is called C4.
Formula bar: the bar near the top of the spreadsheet. It shows what is inside the selected cell, and you can edit the cell there too. Next to it is a small box showing the cell’s reference.

Formulas

A formula is an instruction that tells the spreadsheet to work something out.

Every formula starts with the equals sign =. The equals sign tells the spreadsheet, “This is a calculation, not just text.”

Inside a formula you can use the symbols + add, - subtract, * multiply and / divide, as well as cell references. Because the formula uses references, the answer updates by itself when a number changes.

Functions

A function is a ready-made formula that is already built into the spreadsheet.

Function: a preset formula. You give it a range of cells, and it does the work. Without functions, adding 50 cells would mean typing 50 plus signs!

How to write one

Start with =, then the function name, then the range inside brackets. A range is written with a colon between the first and last cells. Functions do not need spaces.

=SUM(B3:B9)

This reads: “Add up the cells from B3 to B9.” Capital letters are neater, but spreadsheets also understand small letters.

SUM

Adds up the numbers in a range.

AVERAGE

Finds the average: it adds the numbers, then divides by how many there are.

MIN

Finds the smallest (lowest) value. Think “minimum”.

MAX

Finds the biggest (largest) value. Think “maximum”.

COUNT

Counts how many cells contain numbers in a range. It skips words.

Spot the difference: SUM adds the values together. COUNT only counts how many number cells there are. If five cells hold 10, 20, 30, 40 and 50, SUM gives 150 but COUNT gives 5.

Keeping a reference fixed

When you copy a formula down a column, the cell references change to match the new row. Usually that is helpful. Sometimes it causes trouble.

Absolute reference: a cell reference that stays locked when the formula is copied or moved. You make one by putting a dollar sign $ before the column letter and the row number. So D1 becomes $D$1.

A normal reference is a relative reference. It moves with the formula.

Handy tools

These features save time and make a spreadsheet clearer.

Autofill

Fills in cells for you by copying a pattern from the cells next to it. Select the cells, then drag the small square in the corner (the fill handle).

Sort

Puts data in order. Ascending means smallest to largest, or A to Z. Descending means largest to smallest, or Z to A. Works on numbers and on words.

Merge cells

Joins several cells into one larger cell. It is often used for a title across the top of a table.

Fill colour

Changes the background colour of a cell. Use it to make headings stand out.

Chart

Turns your numbers into a picture, so patterns are easier to see.

Do not mix up: “fill colour” changes the background of a cell. The font colour changes the letters. “Autofill” is about filling in values, not colours.

Type it like a pro

Practise writing functions exactly as you would type them. Use the formula bar rules: start with =, write the function name, then brackets with the range inside, and no spaces.

The pattern: =NAME(first:last). The colon means “all the cells from the first one to the last one”. When you are asked to write a function exactly as you would type it, include the = at the start unless the question tells you otherwise.
