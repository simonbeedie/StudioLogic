Level 3

Crane Control — Two Deliveries

🏆 Your mission

The hardest challenge yet. There are two balls and two baskets. You must deliver each ball to its matching basket — the red ball to the red basket, the blue ball to the blue basket.

There are no command buttons this time. You must type all your instructions, including the new repeat() command. Think carefully about reusing patterns in your code.

Task — two deliveries

Red ball (col 1, row 5) → Red basket (col 4)  |  Blue ball (col 7, row 4) → Blue basket (col 9)

Red ball → basket
Blue ball → basket
Command reference
move_right(3) # slide crane right 3 units move_left(2) # slide crane left 2 units lower_hook(4) # lower cable 4 rows raise_hook(4) # raise cable 4 rows grab() # pick up ball at hook position drop() # release ball repeat(5, move_right) # same as move_right(5)
  • Plan both deliveries on paper. Each ball has a different column and row.
  • After completing the first delivery, return the crane and hook to a good starting position for the second pick-up.
  • Use repeat(n, move_right) to practise loop syntax — no quotes needed around the function name this time.
  • The two ball colours are tracked separately — the program checks you deliver each one to the correct basket.
