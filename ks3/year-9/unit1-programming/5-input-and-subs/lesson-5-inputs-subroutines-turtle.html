🐢 The scenario

A robot turtle is drawing patterns in the sand on a beach. To tell it what to draw, we need to take inputs from the user — things like how big a shape should be, or how many sides it should have. Before the turtle can use those inputs, Python needs to know what type of data they are.

Key concept — input() and type conversion

input() always gives you a string — even if the user types a number. If you want to do maths with it, you must convert it first.

int(input()) — converts the input to a whole number (integer)
float(input()) — converts to a decimal number
str(input()) — keeps it as text (this is already the default)

Example: size = int(input("How big? ")) — stores what the user types as a number, so you can use it in calculations.

📐 Why subroutines?

Instead of writing the turtle commands for a square over and over, we can wrap them in a subroutine — a named block of code we can call whenever we need it. We can pass in a parameter to control the size, so one subroutine can draw any size square.

Key vocabulary

TermWhat it meansIn the turtle example
SubroutineA named block of code you can call from anywhere in your programThe whole draw_square block
ProcedureA subroutine that does something but does NOT return a valuedraw_square(50) — it draws, but gives nothing back
FunctionA subroutine that DOES return a value using returncalculate_perimeter(50) — gives back a number
ParameterThe variable name in the definition — a placeholder for the value that will be passed insize in def draw_square(size):
ArgumentThe actual value you pass in when you call the subroutine50 in draw_square(50)
CallThe line that runs the subroutinedraw_square(50) anywhere in the program
DefinitionThe block starting with def — where you write what the subroutine doesdef draw_square(size):
returnSends a value back to whoever called the functionreturn perimeter inside a function
B
Annotated example — procedure vs function
Study the two examples carefully before answering the questions

This is a procedure — it does something (draws) but does not return a value:

def draw_square(size): # ← definition. "size" is the parameter     for i in range(4):         forward(size) # ← uses the parameter         right(90) draw_square(50) # ← call. 50 is the argument draw_square(100) # ← same procedure, different argument

This is a function — it returns a value:

def calculate_perimeter(size): # ← definition     perimeter = size * 4     return perimeter # ← returns a value p = calculate_perimeter(50) # ← stores the returned value print(p) # ← prints 200

🐢 How the turtle works

The turtle starts in the middle of the sandy canvas, facing right. You control it with these commands — write them inside a def function, then call it:

forward(n) — move n pixels forward  ·  backward(n) — move back  ·  right(angle) — turn right  ·  left(angle) — turn left
penup() — lift the pen (move without drawing)  ·  pendown() — put the pen back down
color("red") — change the drawing colour  ·  goto(x, y) — jump to a position
