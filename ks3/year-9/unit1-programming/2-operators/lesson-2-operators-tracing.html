Challenge 1 Arithmetic Operators

Use the four main arithmetic operators to calculate and print four results. The starter code shows you the first one.

the result of a + b, then a - b, then a * b, then a / b
Challenge 2 Powers and Remainders

Practise using ** (power) and % (modulo / remainder).

Your task:
• Print 2 ** 4 (2 to the power of 4)
• Print 17 % 5 (the remainder when 17 is divided by 5)
• Print 3 ** 3 (3 cubed)
Challenge 3 Simple if / else

Write a program that checks whether a number is greater than 10. The structure is started for you — complete it.

Your task: Set number = 15. If it is greater than 10, print "Big number". Otherwise print "Small number". Try changing the value to test both branches.
Challenge 4 Grade Calculator

Use if, elif, and else to build a grade boundary checker. You need three conditions.

Your task:
Set mark to any number. Then:
• If mark is >= 70, print "Distinction"
• Else if mark is >= 50, print "Pass"
• Otherwise print "Not yet"
Challenge 5 Extension — Biggest Number

This is the toughest challenge. You need to compare three variables and print the largest one. Think carefully about which conditions you need.

Your task: Given a = 14, b = 26, c = 23 — write an if / elif / else program that prints whichever is the biggest value. Try changing the numbers to test all three branches.
Challenge 6 Even or Odd

Use the % operator to check if a number is even or odd. A number is even if the remainder when divided by 2 is 0.

Starting variables — write the rest yourself:
number = 17

If the remainder of number % 2 equals 0, print "Even". Otherwise print "Odd". Try changing number to test both outputs.
Challenge 7 Temperature Check

Temperatures fall into three categories — hot, warm, or cold. Your program should read a temperature and decide which category it belongs to.

Starting variable — write the rest yourself:
temp = 22

When you run it with 35 it should print "Hot", with 22 it should print "Warm", and with 8 it should print "Cold". Think about where the boundaries between categories should be.
Challenge 8 Ticket Price Calculator

A cinema charges different prices depending on the customer's age. Children pay less, adults pay full price, and there's a rate in between for teenagers.

Starting variable — write the rest yourself:
age = 14

Your program should print "Ticket costs £" followed by the correct price. When you test with age 8 it should cost £4, age 14 should cost £6, and age 30 should cost £9.
Challenge 9 Score Multiplier

A game multiplies a base score to calculate a final total, then rates that total as high, medium, or low. You will need to use a multiplication operator before writing your selection.

Starting variables — write the rest yourself:
base_score = 45
multiplier = 3

Your program should print the total score and then a rating. Try different values of base_score and multiplier to make sure all three ratings can be reached.
Challenge 10 Extension — Power Check

The ** operator raises a number to a power. Your program should calculate a result and check whether it hits a specific target value — then investigate whether that target is even reachable.

Starting variables — write the rest yourself:
base = 3
exponent = 4

Raise base to the power of exponent and print the result along with a message saying whether it equals 100 or not. Then experiment with different values — can you find whole number values of base and exponent that give exactly 100?
